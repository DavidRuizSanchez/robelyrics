# Capturas de las funcionalidades de la web

Aquí van las capturas que se publican en Instagram para enseñar qué hay dentro
de Entre Interiores. Los nombres los fija `data/instagram_product.yaml`:

| Fichero | Qué capturar |
|---|---|
| `consultorio.png` | `/biblioteca/consultorio` con una pregunta hecha y su respuesta |
| `buscador-semantico.png` | `/biblioteca?mode=semantic` con resultados y el bloque «encaja ·» |
| `karaoke.png` | Una ficha de canción privada con el verso iluminado |
| `listas-mood.png` | `/biblioteca/listas` con las chips de mood y una lista montada |

**Cómo hacerlas**: entra con tu cuenta, deja la pantalla en un estado bonito
(con contenido real, no vacío) y captura. Vertical u horizontal da igual: el
generador recorta y compone.

**Si falta un fichero**, el generador salta esa funcionalidad en vez de publicar
un post que promete enseñar algo y no lo enseña.
